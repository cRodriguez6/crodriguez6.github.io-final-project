Project Goal:¶

Our initial project goal was to analyse TSA data to see if the speed or efficency of TSA has changed over time by analyzing metrics such as total passengers traveling through TSA and speed in which TSA processes said passengers, in comparison with upgrades to TSA systems and global security events. Over time, however, our focus shifted to analyzing flight delay times, specifically Southwest airlines flights departing from MSY. Our current project goal is to create a regression model which aims to use historical data from these Southwest flights to predict future flight delay times.

Table 1 - Airport Population by Day:¶

Our first dataset comes from https://data.bts.gov/Aviation/Commercial-Aviation-Departures-and-TSA-Screenings-/hvq3-38u5/about_data. This data set shows the amount of passengers processed by TSA on different dates, for both domestic and international flights starting in 2019, with the most recent update in 2023. The question we hope to answer with this data is how did the amount of both domestic and international passengers coming through TSA everyday change overtime. There are 6 variables, and 4115 observations. The variables are mode of transportation (all are aviation), indicator (a variable indicating what "current" represents, either domestic, international, or both), date, "current" (a number indicating the amount of people processed through TSA in that week), the week number, and the year. Interestingly, a majority of the dates covered repeat three times, one for each value of indicator.

import pandas as pd
import numpy as np

#This function converts time to minutes froim midnight
def time_to_minutes_transformer(X):
    if X.empty:
        return np.array([]).reshape(0, 1)
    return X.iloc[:, 0].apply(lambda t: pd.to_datetime(t, format='%H:%M').hour * 60 + pd.to_datetime(t, format='%H:%M').minute).values.reshape(-1, 1)

#Split data up by type
categorical_features = ['Destination Airport']
time_features = ['Scheduled departure time']
numerical_features = ['total_passengers', 'month', 'day']

#Preprocessor
preprocessor = ColumnTransformer(
    transformers=[
        ('cat', OneHotEncoder(handle_unknown='ignore'), categorical_features),
        ('time', FunctionTransformer(time_to_minutes_transformer, validate=False), time_features),
        ('num', 'passthrough', numerical_features)
    ],
    remainder='drop'
)

Examples
--------

    The simplest way to use nbconvert is

            > jupyter nbconvert mynotebook.ipynb --to html

            Options include ['asciidoc', 'custom', 'html', 'latex', 'markdown', 'notebook', 'pdf', 'python', 'qtpdf', 'qtpng', 'rst', 'script', 'slides', 'webpdf'].

            > jupyter nbconvert --to latex mynotebook.ipynb

            Both HTML and LaTeX support multiple output templates. LaTeX includes
            'base', 'article' and 'report'.  HTML includes 'basic', 'lab' and
            'classic'. You can specify the flavor of the format used.

            > jupyter nbconvert --to html --template lab mynotebook.ipynb

            You can also pipe the output to stdout, rather than a file

            > jupyter nbconvert mynotebook.ipynb --stdout

            PDF is generated via latex

            > jupyter nbconvert mynotebook.ipynb --to pdf

            You can get (and serve) a Reveal.js-powered slideshow

            > jupyter nbconvert myslides.ipynb --to slides --post serve

            Multiple notebooks can be given at the command line in a couple of
            different ways:

            > jupyter nbconvert notebook*.ipynb
            > jupyter nbconvert notebook1.ipynb notebook2.ipynb

            or you can specify the notebooks list in a config file, containing::

                c.NbConvertApp.notebooks = ["my_notebook.ipynb"]

            > jupyter nbconvert --config mycfg.py

To see all available configurables, use `--help-all`.
